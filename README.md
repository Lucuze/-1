# 🌟 특수교육 배움터

> 교육학개론 수업용 — 특수교육 대상 초등학생을 위한 AI 활용 학습 앱

## 소개

특수교사를 꿈꾸는 대학교 1학년 학생이 AI를 활용하여 만든,  
**특수교육 대상 초등학생**이 즐길 수 있는 웹 기반 학습 앱입니다.

## 주요 기능

| 활동 | 설명 |
|------|------|
| 🎨 **색깔 맞추기** | 목표 색을 보고 같은 색을 골라요 (10점 적립) |
| 🔢 **숫자 세기** | 이모지를 세어보고 맞는 숫자를 골라요 (10점 적립) |
| 📖 **단어 배우기** | 그림을 보고 맞는 단어를 골라요 (10점 적립) |
| 🤖 **AI 도우미** | 색깔·숫자·동물·과일 등 무엇이든 물어볼 수 있어요 |

## 접근성 (Accessibility)

- 큰 버튼과 글씨로 조작 쉽게 설계
- 고대비 색상과 명확한 시각 피드백
- 키보드 내비게이션 완전 지원 (`Tab` / `Enter`)
- `aria-label`, `aria-live` 등 스크린리더 지원
- `prefers-reduced-motion` 미디어 쿼리 대응

## 실행 방법

별도 설치나 서버 불필요 — 브라우저에서 바로 실행!

```
app/index.html  파일을 브라우저로 열면 바로 시작됩니다.
```

## 파일 구조

```
app/
├── index.html   # 메인 HTML
├── style.css    # 스타일시트
└── app.js       # 게임 로직 & AI 도우미
```

## 기술 스택

- **HTML5 / CSS3 / Vanilla JS** — 프레임워크 없이 순수 웹 기술만 사용
- **규칙 기반 AI 응답 엔진** — 학생의 질문에 맞는 친절한 답변 제공
- **Progressive Enhancement** — 모든 최신 브라우저에서 동작
