# 한글 모험대 🌟

지적장애 초등 저학년(1~2학년 수준) 학생들이 한글과 읽기 개념을 재미있게 학습할 수 있는 웹 기반 게임 앱입니다.  
갤럭시 태블릿(Android 브라우저)에서 인터넷 환경으로 사용하며, 특수교사가 수행평가 도구로 활용합니다.

---

## 🎯 대상
- **장애 유형**: 지적장애
- **연령대**: 초등 저학년 (1~2학년 수준)
- **기기**: 갤럭시 태블릿 (Android / Chrome 브라우저)

---

## 🕹️ 게임 모드

### 1. 그림-단어 맞추기 🖼️
이모지 그림을 보고 알맞은 단어를 4개 보기 중에서 고르는 게임입니다.  
초등 2학년 수준의 단어 24개(사과, 강아지, 자동차, 책, 꽃, 물고기, 집, 연필, 달, 별, 바나나, 고양이, 버스, 가방, 무지개, 피자, 개구리, 장미, 풍선, 새 등)가 포함됩니다.

### 2. 글자 조각 맞추기 🔤
흩어진 음절 카드를 올바른 순서로 눌러 단어를 완성하는 게임입니다.  
2~3음절 단어 18개(사과, 강아지, 자동차, 고양이, 무지개, 바나나, 피자, 개구리, 풍선, 가방, 연필, 버스, 물고기, 장미, 달팽이, 나비, 하늘, 토끼)가 포함됩니다.

### 3. 문장 완성하기 📝
짧은 문장의 빈칸에 알맞은 단어를 3개 보기 중에서 고르는 게임입니다.  
초등 2학년 수준의 문장 15개가 포함됩니다.

---

## 👩‍🏫 교사 모드 사용법

1. 메인 화면 하단의 **🔐 교사 모드** 버튼을 누릅니다.
2. 비밀번호 **1234** 를 입력합니다.
3. 학생별 플레이 기록(이름 / 게임 모드 / 정답률 / 날짜)을 확인할 수 있습니다.
4. **기록 전체 삭제** 버튼으로 누적 기록을 초기화할 수 있습니다.

---

## 📊 수행평가 활용 방법

1. 학생이 게임을 완료하면 **결과 화면**에서 총 문제 수, 맞은 수, 정답률(%), 별점이 자동 표시됩니다.
2. **📋 교사에게 보여주기** 버튼을 누르면 결과가 전체화면으로 크게 표시되어 교사가 한눈에 확인할 수 있습니다.
3. 모든 결과는 브라우저 **localStorage**에 누적 저장되므로, 여러 학생의 기록을 교사 모드에서 열람할 수 있습니다.
